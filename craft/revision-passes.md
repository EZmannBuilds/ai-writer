# Craft Revision Passes
## AI Writer v0.4

Do not line-edit a structurally broken story.

Order:

```text
STORY PHYSICS
→ SCENE FUNCTION
→ ENTRY / EXIT
→ SHOW / TELL
→ POV DISTANCE
→ DIALOGUE / SUBTEXT
→ EXPOSITION
→ SPECIFICITY
→ SETUP / PAYOFF
→ PACING / RHYTHM
→ READER TRUST
→ LINE EDIT
```

## Pass notes

### Story physics
Check motivation, causality, chronology, world rules.

### Scene function
What state changes? Cut/merge/compress scenes with no deliberate function.

### Entry / exit
Test removing warm-up and explanatory aftermath.

### Show / tell
Dramatize consequential moments. Compress logistics.

### POV
Check knowledge, distance, filtering, head-hopping.

### Dialogue
Check tactics, hidden sentence, exposition, read-aloud naturalness.

### Exposition
Release only what current action needs.

### Specificity
Replace generic labels with selective evidence. Remove inventories.

### Setup / payoff
Track promises and missing seeds.

### Pacing
Vary scene/summary, sentence/paragraph density, emotional intensity.

### Reader trust
Delete explanations the reader can already infer.

### Line edit
Only after the architecture is stable:
- syntax;
- diction;
- modifiers;
- repetition;
- sound.
